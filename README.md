# Desire Sync

A [Chickadee Bandit](https://chickadeebandit.com/app-library/desire-sync) app.

A private, mutual way for partners to signal interest — only nudges both of you when your signals align.

## Features

- A private signal from each partner; neither sees the other's.
- A match is evaluated on the server and revealed to both simultaneously.
- Signals expire after a set window, and both are cleared on a match.
- Reciprocal partner setup — each person names the other.
- Visible to nobody else in the household. Adults only.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-desire-sync/releases/latest/download/bundle.json
```
